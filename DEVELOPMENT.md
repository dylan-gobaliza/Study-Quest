# Study Quest

## 1. Hackathon — The Original Idea

Seeing people compete in hackathons always interested me: a time limit, a brief, a good presentation and I thought why not? I stumbled onto devpost and found a simple hackathon for beginners and applied to it. One of the themes were school and being innovative and from there I built Study Quest.

## 2. Learning Python Through Study Quest

I learnt lots of skills and it forced me into places where I had to learn and use new concepts in a fixed amount of time. Dictionaries took me 1-2 hours to get familiar with, but it really helped clean the code rather than making multiple nested arrays/lists. Below are skills used:

- Input/output
- Variables
- Conditionals
- Loops
- Lists
- Dictionaries
- Functions
- Parameters and arguments
- Returning values
- Debugging
- Turning ideas into algorithms

## 3. Developing the Project

There's so many roadblocks that were hit during that weekend, but nevertheless i still managed to overcome them. Furthermore, my original plan stemmed out into so many additional features that I never would have considered at the start which is why this project was so valuable. I learnt that you should just 'do' rather than brainstorm and brainstorm and brainstorm.

## 4. Hackathon Submission

Arguably the most nerve-wracking part - the submission. Recording my own video wasn't easy and I had to really focus for that. I remember seeing other applicants with powerpoints and facecams but to be honest it didn't shake me that much, I never actually joined it to win (however unbelievable it sounds) but I wanted to have the experience of doing it. 

## 5. After the Hackathon

Now I'm learning javascript, CSS and html to transform the terminal based program into - hopefully - a working website! I plan to have no AI make any part of it; only to assist and guide me. This helps me not only understand code but also write it needless of external help in the future.

## 6. Future Ideas

Hopefully when it's finished I can recommend it to friends and family to use!
